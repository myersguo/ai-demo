# 兵棋设计工坊

面向懂军事业务、但不熟悉兵棋设计的用户的兵棋设计助手。按六个步骤完成设计，并直接进入人工推演与复盘。

| 步骤 | 内容 |
|---|---|
| 1 作战场景 | 想定名称、层级（战术/战役/战略）、攻防关系、时空参数、地形、天候、电磁环境、想定背景，实时地图预览与时空换算检查 |
| 2 参演力量 | 红蓝双方兵力编成（12 类兵种 × 4 级梯队 × 战备程度），自动生成 NATO 风格棋子与攻-防-机动值，兵力比分析 |
| 3 推演目标 | 推演目的、研究问题、四类目标（夺控/坚守/歼敌/保存实力）与胜利点 |
| 4 规则设置 | 回合阶段序列、CRT/混合/专家裁决、1d6/2d6、开放/双盲、控制区、补给、指挥控制、事件频率，按场景给出推荐 |
| 5 兵棋方案 | 生成六角格地图与部署、兵力编成表、胜负判定、回合流程、战斗结果表、地形效果表、事件卡、蒙特卡洛平衡性估算、设计检查清单，可导出 Markdown |
| 6 人工推演 | 可交互棋盘：机动范围计算、控制区、堆叠、攻击目标与支援协同、栏移、掷骰查表、白方改判与调整、事件抽取、红/蓝/白视角（双盲迷雾）、撤销、推演记录，结束后生成复盘报告（胜利点与战斗步走势、目标达成） |

在 Claude 中打开时，还可以调用 Claude 起草想定背景、评审方案并建议情况注入、撰写复盘评述。

所有地名、番号均为虚构示例。

## 运行

纯前端单页应用，无需安装依赖：直接用浏览器打开 `index.html`，或部署到任意静态托管 / CDN。

项目数据保存在浏览器 `localStorage`，可通过“导出项目 JSON / 导入项目 JSON”备份和迁移。

## 开发

源码位于 `src/`：

- `styles.css` 样式与明暗主题
- `data.js` 兵种、地形、模板、术语等静态数据
- `engine.js` 六角格几何、地图生成、方案生成、裁决与推演引擎、平衡性模拟
- `ui.js` 视图渲染与交互
- `shell.html` 页面骨架

修改后执行 `node scripts/build.mjs`，生成 `index.html`（完整页面）与 `dist/app.html`（页面片段，用于发布为 Claude Artifact）。
